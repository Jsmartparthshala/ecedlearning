# Clickable prototype

Single-file HTML mock of the TV interface, built before any Kotlin was written so
the screen flow could be agreed on cheaply. Open `index.html` in a browser — no
build step, no dependencies, no network calls.

Drive it with the arrow keys; `Enter` selects and `Backspace` goes back. It is a
fixed 1920×1080 canvas scaled to the window, so it shows what a classroom
television shows.

Kept for reference. It is **not** the product and is not maintained alongside the
Android app — where the two disagree, the Android app is correct.
